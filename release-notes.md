# VoxTube v1.1.1

**Release date:** 2026-11-27
**Status:** Stable

A polish update for the Liquid Glass look: a cleaner, icons-only tab bar, headers without edges, and pill chips.

## Download

| File | What it is |
|---|---|
| `voxtube.apk` | Universal build. Updates itself from inside the app. **Pick this if unsure.** |
| `voxtube-arm64-v8a.apk` | Smaller build for most modern phones (64-bit ARM) |
| `voxtube-armeabi-v7a.apk` | Smaller build for older 32-bit phones |
| `voxtube-foss.apk` | FOSS build without the built-in updater and Discord integration (also as `voxtube-foss-arm64-v8a.apk` and `voxtube-foss-armeabi-v7a.apk`) |
| `checksums.txt` | SHA-256 of every APK |
| Source code (zip / tar.gz) | The full source of this release |

Android 8.0 or newer. Updates over VoxTube 1.1.0 and 1.0.0 in place.

## Improved

- The floating tab bar shows icons only by default, with a calmer neutral selection pill (names can be turned back on in Settings > Appearance > Navigation bar)
- Headers are the page's own colour at rest and frost as the feed scrolls under them, with no edge or shadow
- Filter chips are pills
